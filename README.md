# comp120tictactoe

run this c program in a compiler of your choice.

Play tictactoe against a random number generator!. 

all input cases are handled (number outside of range, text input, multiple charecter input) and properly diplays error/invalid input
all possible ways to win are handled (player win, computer win, draw) and properly displays the winner 

i made the game display numbers 1-9 because it was more comfortable for the average user instead of 0-8

the program makes use of loops, bools, functions, strings and string manipulation, input handling etc.
